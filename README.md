# 双随机高效专注计时器（Dual-Random Focus Timer）

一款基于神经科学原理——**超昼夜节律（Ultradian Rhythm）**与 **Andrew Huberman 间隙效应（Gap Effect / 10 秒神经重放）**——构建的纯前端单文件专注计时器。零外部依赖、零音频文件，打开浏览器即可离线使用。

## 核心特性

### 1. 双层专注节律
- **宏观周期（超昼夜节律）**：默认单轮 90 分钟专注，支持 60 / 75 / 90 分钟快速预设与 60–90 分钟自由微调；倒计时结束后自动播放舒缓和弦，提示进入 **10–15 分钟大休**（内置一键启动 10/15 分钟大休计时）。
- **隐藏式微观触发（随机间隙效应）**：专注期间，后台持续在 **3–5 分钟（180–300 秒）** 之间完全随机生成微休息触发点。界面刻意**不显示**微观倒计时秒数，仅保留极简呼吸光晕，避免大脑产生时间预期和焦虑。
- **10 秒神经重放（微休息）**：提示音响起后自动进入 10 秒闭眼微休息倒计时；结束后可选择轻柔恢复提示音或静默恢复，并立即开启下一轮随机周期。

### 2. Web Audio API 防习惯化声学引擎
- **零外部音频文件**：全部声音通过代码实时合成，内置立体声空间混响（Convolver）与动态柔化压缩器。
- **三重随机防习惯化**：
  - **音高随机**：从和谐的五声音阶（G3–E5）中不连续重复地随机抽取。
  - **音色随机**：在 5 种自然合成乐器间随机切换——**空灵手碟**、**喜马拉雅颂钵**、**温润卡林巴**、**风铃竖琴**、**禅意雨滴**。
  - **音量微扰**：在基础音量上自动叠加 ±10% 的轻微随机浮动。
- **防惊吓平滑包络（ADSR）**：所有提示音均带有 35–80ms 平滑淡入与 0.9–1.5s 自然衰减，杜绝刺耳爆音。

### 3. 极简护眼界面与实用控制
- 低对比度深邃夜间主题，支持响应式桌面双栏与移动端单栏布局。
- 支持开始 / 暂停（`Space` 空格快捷键）、重置、单独试听 5 种音色、随机试听、全局静音与微休息结束音开关。
- 自动记录本轮已完成的 **10 秒神经重放次数**与累积专注时长，本地自动记忆个人偏好设置。

## 快速使用

### 方式一：本地直接运行
1. 下载 `dual_random_focus_timer.html`（或已重命名的 `index.html`）。
2. 双击文件在任意现代浏览器（Chrome / Edge / Safari / Firefox）中打开即可使用，完全支持离线运行。

### 方式二：通过 GitHub Pages 在线访问
1. 将 HTML 文件命名为 `index.html` 并上传至仓库根目录。
2. 进入仓库 **Settings → Pages**，在 **Branch** 中选择 `main` 分支并点击 **Save**。
3. 等待约 1 分钟即可通过生成的 GitHub Pages 链接在电脑或手机浏览器中随时打开。

## 使用建议
1. 开始前先点击**「试听随机音色」**或右侧的 5 个音色标签，将音量调至舒适但不突兀的水平。
2. 听到微休息提示音时，立即**闭眼静坐、停止视觉与文字输入**，安静度过 10 秒让海马体与新皮层完成快速神经重放。
3. 完成一轮 60–90 分钟专注后，尽量离开屏幕休息 10–15 分钟，再进入下一轮专注。
